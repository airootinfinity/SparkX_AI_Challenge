# worlds/

Competition worlds made with `python3 hosting/sparkx_host.py new-world ...` land here, one folder
per world. Each `<world>/private/` folder is the answer sheet (survivor positions, clues).

**Never commit, upload or share anything in this folder**, and never write the seed of a
competition world anywhere public. `../.gitignore` keeps it out of git; do not force-add it.

The practice world shipped in `sparkx_ws/` (`practice_small_day`) is offered by the host tool as
well, so you can test the whole pipeline before you make any world here.
